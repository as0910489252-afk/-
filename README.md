# 尾牙王者爭霸賽（50 人即時多人版）

一個可部署的手機網頁派對遊戲：主持人投影、玩家手機加入、5 隊自動平衡、即時團隊積分、5 題趣味問答與伺服器端隨機抽獎。

## 功能
- 主持人建立六位數房間碼
- 最多 50 位玩家加入，暱稱不可重複
- 玩家加入時自動平均分成 5 隊
- 主持人開始、逐題切換、結算冠軍
- 玩家手機作答，答對為隊伍增加 100 分
- 隊伍積分與玩家名單即時更新
- 主持人可從已加入玩家中抽出一位得主
- 手機與投影螢幕共用同一個即時房間

## 本機測試
需要 Node.js 20 或更新版本。

```bash
npm install
npm start
```

瀏覽器開啟 `http://localhost:3000`。
同一個 Wi-Fi 下的手機可開啟電腦的區域網路 IP，例如 `http://192.168.1.20:3000`。作業系統防火牆需允許連線。

## 部署到 Render（簡易方式）
1. 將整個資料夾推送到自己的 GitHub repository。
2. 在 Render 建立 **Web Service** 並連接該 repository。
3. Build Command：`npm install`
4. Start Command：`npm start`
5. 部署完成後，使用 Render 提供的 HTTPS 網址。
6. 投影頁面由主持人建立房間；玩家用同一個網址開啟頁面並輸入房間碼。

## 現場流程建議（約 15 分鐘）
- 0:00–2:00 主持人建立房間、全員加入
- 2:00–3:00 說明規則並平均分隊
- 3:00–10:00 五題快問快答，每題約 60–80 秒
- 10:00–12:00 顯示隊伍排名與冠軍
- 12:00–15:00 抽獎、核對得主、拍照

## 重要限制與正式活動前檢查
- **目前為記憶體房間狀態**：若服務重新啟動或重新部署，房間與分數會清除；單一服務實例適合一次性活動。不要開啟多個服務實例，否則各實例的房間狀態不共享。
- 主持人重新整理或斷線後，原房間的主持權不會自動恢復；建議主持人設備使用穩定 Wi-Fi，並在活動前完整彩排。
- 抽獎是從目前已加入房間的玩家中等機率抽一位；不支援排除已得獎者、分獎品層級或保存稽核紀錄。
- 目前沒有登入、身分驗證、持久化資料庫、抽獎稽核紀錄、主持人密碼或封鎖惡意玩家功能。
- QR Code 可用任何 QR 產生器把部署網址轉成 QR；玩家仍需輸入房間碼。請勿把房間碼當成安全驗證。
- 建議活動前以 50 台手機或模擬連線壓力測試，確認場地 Wi-Fi、投影、音響及行動網路備援。
- 若抽獎涉及正式獎項或合規要求，主辦單位應事先公布規則並保存得獎紀錄；此版本的抽獎為簡易隨機選取，不是可稽核的正式抽獎系統。

## 可客製
修改 `server.js` 中的 `QUESTIONS` 陣列即可更換題目、選項與正確答案；隊伍名稱可修改 `TEAM_NAMES`。
